<h1 align="center">ЛИФТ</h1>

## Идея
Лифт - это динамичный 2D рогалик с видом сверху. 
Игрок заходит в обычный лифт своего дома, но двери открываются в иное измерение - таинственный лабиринт. Задача героя - пробиться через орды врагов и процедурно генерируемые этажи, чтобы найти выход.

## Тип проекта
Игра. 


## Цель
Разработать динамичный 2D-рогалик с процедурной генерацией уровней, который объединяет высокоскоростной брутальный геймплей и вариативность оружия. 

## Задачи 
- [ ] Проектирование и архитектура: разработать масштабируемую архитектуру игры с четким разделением данных (модели оружия, врагов) и логики.
- [ ] Процедурная генерация: создать алгоритм генерации комнат/уровней (например, на основе Drunkard's Walk и/или алгоритма разделения BSP), обеспечивающий высокий темп прохождения без тупиков.
- [ ] ИИ врагов: Написать алгоритмы поведения противников (поиск пути, ближний/дальний бой, координация группами и т.п.).
- [ ] Боевая система: реализовать механику отзывчивого управления, расчета попаданий, эффекта сочности ударов (game feel: screen shake, частицы и т.п.).
- [ ] Система прогрессии: разработать архитектуру модификаторов, механик "roguelike" (постоянные улучшения между забегами) и "roguelite" (случайные предметы внутри сессии).


## Части системы 
***Этот список следует воспринимать не как конечную архитектуру кода (цель), а как некоторую заготовку.***
- Core Gameplay Manager: управляет состояниями игры (меню, игровой процесс, пауза, экран смерти) и глобальными триггерами.
- Level Generator: отвечает за создание сетки комнат, расстановку врагов, сундуков, препятствий и прочих вещей.
- Entity Controllers:
  - Player Controller - обработка ввода, физика движения, механика рывков/уворотов.
  - Enemy Controller - спавн, логика ИИ, пули и паттерны атак.
- Combat & Inventory System: хранит характеристики оружия, просчитывает урон, накладывает эффекты (горение, заморозка и т.д.) и управляет инвентарем/активными слотами.
- UI/UX Layer: динамическое отображение здоровья (HUD), миникарта, экран выбора перков, инвентарь и главное меню.
- Save/Load System: cериализация мета-прогресса игрока (открытое оружие, валюта) между сессиями.


## Технологии

- Графика: **Krita**
- Музыка и звуки: **FL Studio**
